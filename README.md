# Work (Physics) Training App

A simple Streamlit app for practicing calculations of **work** in junior high school physics.

This app generates random practice problems and lets learners input answers, then automatically scores and explains the results.

## Overview
In junior high school science, students often struggle with unit conversion and formula-based calculations.
This app helps students practice the basic relationship:

- **Work (J) = Force (N) × Distance (m)**

The goal is to support learning through repetition and immediate feedback.

## Features
- Randomly generates multiple questions per session
- Input answers directly in the app
- Automatic scoring with tolerance for small decimal errors
- Shows each question’s correct answer and explanation
- “Create new questions” button to refresh the problem set

## Educational Use Cases
- Warm-up practice at the start of a class
- Homework / self-study for calculation skills
- Quick formative assessment (check understanding)
- Practice for tests that include work and energy topics

## Technologies Used
- Python
- Streamlit

## Notes
- This project is intended for educational and practice use.
- The scoring allows a small numerical tolerance to handle rounding differences.
